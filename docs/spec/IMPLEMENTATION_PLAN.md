## 1. 项目目标

构建一个 Python 命令行工具，将本地 PDF/DOCX/DOC/TXT 文件通过远程 API 批量转换为 Markdown 格式。

**核心需求**:
1. 命令行接受文件路径或目录路径
2. 将文件转为 Base64 后调用远程 API
3. API 返回的 Markdown 内容存为 .md 文件到 output/ 目录
4. 文件重名时追加随机后缀
5. 可配置的 API 地址、重试次数等（conf/setting.json）
6. 日志放到 logs/ 目录，按天存储，包含关键信息
7. 退出码: 0=全部成功, 1=有失败

## 6. 技术决策记录

| 决策 | 方案 | 理由 |
|------|------|------|
| 架构 | 单文件 | 功能简单，维护成本低 |
| 语言 | Python 3.7+ | 适合脚本，依赖少 |
| 并发 | 无（同步顺序处理） | API 调用是瓶颈，并发增加服务器压力 |
| 路径解析 | 相对于脚本目录 | 用户从任意目录运行都能找到正确位置 |
| 重试策略 | 固定延迟 | 重试次数少，指数退避收益不大 |
| 日志格式 | [时间] 级别  消息 | 简洁易读 |
